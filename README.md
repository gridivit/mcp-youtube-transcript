# mcp-youtube-transcript

MCP-сервер: принимает ссылку на видео YouTube и возвращает агенту текст транскрипта.

## Инструменты

- `list_transcript_languages(url)` — какие языки субтитров доступны у видео
- `get_transcript(url, language)` — текст транскрипта на указанном языке
